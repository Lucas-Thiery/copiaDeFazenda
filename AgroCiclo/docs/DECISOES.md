# Decisões e pendências

| ID | Situação nesta entrega |
|---|---|
| D01 | Sem fazenda real escolhida; testes usam dados fictícios. |
| D02 | Ambiente local e Docker Compose preservados; hospedagem e HTTPS dependem da equipe. |
| D03 | Java 21, Boot 3.5.7, PostgreSQL 18, Flyway 11.15.0. PostgreSQL 18.1 é usado no teste de migrations. |
| D04 | Animal em um lote; lote em pastagem; vínculos e movimentações históricos. |
| D05 | Sessão, login/senha e BCrypt preservados como escolha de desenvolvimento. |
| D06 | Não foi atribuída licença pública nova ao projeto. |
| D07 | Minimização de responses e acesso implementados; política LGPD/retencão ainda não aprovada. |
| D08 | Offline, IoT, integrações fiscais/governamentais e recursos preditivos fora do escopo. |
| D09 | Responsável pós-entrega não escolhido. |
| D10 | Backups e restauração real não executados; periodicidade/responsável a validar. |
| D11 | Sem protocolo de desempenho homologado ou medição dos dois segundos. |
| D12 | Liderança não atribuída. |

As decisões propostas em Document1.pdf foram tratadas como diretrizes de desenvolvimento, não como aprovações formais da equipe ou evidências de operação.
