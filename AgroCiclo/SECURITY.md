# Segurança

Este projeto está em desenvolvimento e ainda não possui todos os controles de segurança previstos. Não o utilize em produção nem armazene dados reais.

Se identificar uma vulnerabilidade, não publique detalhes exploráveis em uma issue pública. Entre em contato diretamente com os mantenedores do repositório por um canal privado definido pela equipe.

Nunca envie senhas, tokens, chaves, dados pessoais ou informações reais de propriedades em issues, commits ou Pull Requests.
